# 上野⇔新潟 最安ナビ（ueno-niigata）

上野⇔新潟の移動をいちばん安くするための、個人用の静的サイト。スマホで見る前提。

## できること
- 方向と乗る日を選ぶと、その日に使える手段を安い順に表示
  - 新幹線eチケット／通常きっぷ／自由席
  - **トクだ値スペシャル28**（50%割引・平日限定・列車/席数限定）: 設定期間か、発売前・発売中・締切済みかを判定
  - **株主優待割引券**（4割引）: 手持ちの券を使うか、金券ショップで買うか（券代込みで計算）
  - **大人の休日倶楽部**（ミドル5%・ジパング30%）: 会員設定したときだけ表示
  - 高速バス（新宿・池袋・東京駅から）、在来線の普通列車
- 「新幹線でいちばん安い」と「時間がかかってもよければ」の2つを要約表示
- 早割の発売日を **カレンダーに登録（.ics）**。発売開始 10:00 の5分前に通知
- JRE POINT 35%OFFキャンペーン期間中はお知らせを表示
- 株主優待・会員の設定はブラウザに保存

## 早割で取れる列車について
トクだ値スペシャル28の対象列車・席数は日ごとに変わり、事前に公開されていない。
えきねっとで発売初日 10:00 に検索し、「トクだ値スペシャル28」と表示された「とき」が対象。
サイトでは発売日の通知と探し方の手順を案内している。

## 使い方
```bash
cd apps/ueno-niigata
npm start   # http://localhost:8000
npm test
```
ビルド不要なので、フォルダごと GitHub Pages などに置けばスマホから見られる。

## データの更新
`src/data.js` の値は 2026年9月に調べたもの。とくに次は変わりやすいので、発表があれば更新する。
- `SPECIAL28_PERIODS`: トクだ値スペシャル28 の設定期間（JR東日本が期間ごとに発表）
- `JRE_POINT_CAMPAIGNS`: JRE POINT 35%OFF の期間
- `SHAREHOLDER.couponMarketPrice`: 株主優待券の相場
- `FARES`: 運賃改定時

## 毎日の自動チェック（GitHub Actions）
`.github/workflows/daily.yml` が毎朝 9:30（日本時間）に実行する。手動実行は Actions タブ → daily-check → Run workflow。
- `scripts/watch-special28.mjs`: トクだ値スペシャル28 の新しいニュース・えきねっとの案内の変化を検知して通知。登録済み期間の発売開始日の朝にも通知
- `scripts/fetch-prices.mjs`: 株主優待券の各店の価格を取得して `data/prices.json` に保存（サイトが読み込んで最安店を表示）

通知先: リポジトリの Secret `NTFY_TOPIC` に ntfy のトピック名を入れると、ntfy アプリに届く。GitHub の Issue にも作成される。
